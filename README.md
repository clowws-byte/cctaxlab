# CCTaxLab

Cheng & Co Group's portal for all tax applications.

- `index.html`: the portal (hosted on GitHub Pages)
- `library.html`: Tax Knowledge Library (newsletters and tax documents; opened from the CCT Library workspace)
- `setup.sql`: database setup for the Supabase project "CCTaxLab" (already applied)

Sign-in, user approval, applications and visibility are managed in the portal under **Admin**.
